# DOCX 兼容性人工检查清单

每个 Windows、Linux 发布候选版本至少使用一份真实业务模板执行一次。检查结果需记录测试日期、应用版本、模板名称、Microsoft Word 版本和 LibreOffice 版本。

## Microsoft Word

- [ ] 双击输出文件可直接打开，无“发现无法读取的内容”或修复提示。
- [ ] 正文、表格、页眉和页脚中的目标板块均已写入，模板占位符无残留。
- [ ] 新增多段内容继承目标段落的字体、字号、颜色、加粗和语言设置。
- [ ] 表格未新增非预期行列，边框、列宽、单元格内边距和分页保持正常。
- [ ] 图片、编号、目录、页码、页眉页脚和分节符保持正常。
- [ ] 保存、关闭并再次打开后内容仍完整，无修复提示。

## LibreOffice Writer

- [ ] 输出文件可直接打开，无格式或损坏警告。
- [ ] 中文字体存在时正文、表格、页眉和页脚均正常显示。
- [ ] 多段内容无裁切、重叠或异常大段空白。
- [ ] 表格未越过页边距，分页可接受。
- [ ] 另存为 DOCX 后可再次打开，关键内容无丢失。

## 结构化结果记录

- [ ] 自动验证结果为 `valid=true`。
- [ ] `unresolved_placeholders=0`。
- [ ] 非目标包部件变化集合为空。
- [ ] 若当前测试机缺少模板所需中文字体，记录字体名称，并在具备该字体的目标 Windows 机器补做视觉检查。
